# Swift Frontend

This directory is reserved for the Swift frontend application.

## Connection to Go Backend

The Go backend server runs on `http://localhost:8080` by default.

### Available API Endpoints:

- **Health Check**: `GET /health`
- **API Info**: `GET /api`
- **Get Users**: `GET /api/users`
- **Post Data**: `POST /api/data`

All endpoints support CORS and return JSON responses.
